# Atelier Lumina — Soft Glass Mobilier

Website e-commerce demonstrativ pentru mobilier premium (ro-RO), construit cu Next.js App Router + TypeScript + Tailwind CSS.

## Rulare locală

```bash
npm install
npm run dev
```

## Publicare pe GitHub Pages

1. În repository, mergi la **Settings → Pages** și setează **Source: GitHub Actions**.
2. Fă push pe `main` cu modificări în `soft-glass-mobilier/` sau rulează workflow-ul manual din **Actions**.
3. După deploy, site-ul va fi disponibil la:

`https://paul-444.github.io/learningStuff/`
